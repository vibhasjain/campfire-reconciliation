# Brilliant canvases for concepts A and B (source)

Byte-for-byte copies of the two concept canvases and the design system from Brilliant's local Scratch project
(`~/.config/brilliant/scratch/`). The static HTML exports served at `/concepts/a-workpaper/` and
`/concepts/b-balance-bridge/` (`public/concepts/`) were made from these. Not served by the site.

To restore, copy the two `.bl` files into the Scratch project folder and `Styles/*.ds` into its `Styles/`.
